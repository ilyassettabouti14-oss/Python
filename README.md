# Python
Dans le cadre de ma formation en cybersécurité j'étudie le langage Python : 
- Description et spécificité par rapport à d'autres langages : Python se distingue des autres langages de programmation par sa conception axée sur la lisibilité du code et la productivité du développeur.
- Origine du nom : Le nom Python ne fait pas référence au serpent, mais à la troupe d'humoristes britanniques Monty Python.
- L'utilité de Python en cybersécurité : En cybersécurité, le temps de réaction est critique. Python est devenu l'outil de référence des analystes SOC, des pentesters et des chercheurs en sécurité pour plusieurs raisons majeures.
- Mon choix d'EDI et ca procédure d'installation : Pour débuter et travailler efficacement en cybersécurité, Visual Studio Code (VS Code) est un excellent choix d'Environnement de Développement Intégré (EDI / éditeur de code avancé). Il est gratuit, léger, multiplateforme et intègre un terminal directement dans son interface.
L'installation de Visual Studio Code (VS Code) s'effectue rapidement en téléchargeant le fichier correspondant à votre système d'exploitation depuis le site officiel visualstudio.com.

Sous Windows

• Téléchargement : Rendez-vous sur le site officiel et cliquez sur le bouton Download for Windows pour récupérer l'installateur (fichier .exe).
• Lancement : Double-cliquez sur le fichier téléchargé et acceptez les termes du contrat de licence.
• Options recommandées : Cochez les cases Ajouter l'action "Ouvrir avec Code" au menu contextuel et Ajouter au PATH pour lancer l'éditeur depuis le terminal.
• Finalisation : Cliquez sur Installer, patientez quelques secondes, puis cliquez sur Terminer pour ouvrir le logiciel.

Sous macOS

• Téléchargement : Cliquez sur Download for Mac sur le site officiel (choisissez la version Apple Silicon ou Intel selon votre processeur).
• Extraction : Double-cliquez sur l'archive .zip téléchargée pour extraire l'application Visual Studio Code.app.
• Installation : Faites glisser l'icône de l'application directement dans votre dossier Applications afin de la rendre accessible depuis le Launchpad.

Sous Linux (Ubuntu, Debian, Kali Linux)

• Téléchargement : Récupérez le paquet .deb depuis la page d'accueil du site officiel.
• Installation via le terminal : Ouvrez un terminal dans votre dossier de téléchargements et lancez la commande sudo apt install ./code_*.deb.
• Lancement : Tapez simplement code dans votre terminal ou recherchez l'icône Visual Studio Code dans le menu de vos applications.
